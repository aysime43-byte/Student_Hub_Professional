BIS Student Management System

التشغيل المباشر بدون server.js أو npm:
1) افتح مجلد public.
2) اضغط مرتين على index.html ليفتح الموقع في المتصفح.
3) نموذج إضافة الطالب ظاهر بالكامل تلقائيًا في الواجهة، دون الضغط على زر إضافة.
4) أدخل الاسم ثم ID ثم الهاتف، وبعدها الدرجات والحضور والتقديرات، ثم اضغط حفظ بيانات الطالب.

الحفظ:
- يتم حفظ البيانات تلقائيًا داخل المتصفح على نفس الجهاز باستخدام Local Storage.
- لا تظهر رسالة Failed to fetch لأن التطبيق لا يحتاج إلى الاتصال بخادم.
- البيانات تبقى في نفس المتصفح ما لم يتم مسح بيانات الموقع/المتصفح.
- البيانات المحلية لا تنتقل تلقائيًا إلى جهاز آخر أو متصفح آخر. للنشر كرابط عام متعدد المستخدمين يلزم استضافة بخادم وقاعدة بيانات.

اختياري: ما زال server.js موجودًا لمن يريد تشغيل نسخة الخادم بالطريقة القديمة، لكنه غير مطلوب للتشغيل المباشر.
